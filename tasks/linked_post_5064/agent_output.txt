## How It Works

1. **Admin configures pages**: In Settings → Email Campaigns, admin selects WordPress pages for opt-in and opt-out
2. **URL generation**: When generating tracking links, the system checks if pages are configured and uses their permalinks
3. **Request handling**: When a user clicks a link:
   - ActionEndpoint detects if it's a WordPress page or custom endpoint
   - For WordPress pages: stores action data in a transient and returns control to WordPress
   - For custom endpoints: renders the full standalone page (backward compatible)
4. **Content filtering**: The content filter detects configured pages and replaces their content with the plugin UI
5. **Data retrieval**: The filter retrieves the action data from the transient and renders the appropriate form

## Backward Compatibility

- If no pages are configured, the system falls back to the original custom URL behavior
- All existing functionality (rate limiting, security checks, action recording) is preserved
- Custom endpoint URLs continue to work as before

## Key Features

- **Seamless integration**: Plugin UI appears as WordPress page content, using the site's theme
- **Security maintained**: All rate limiting, nonce verification, and validation remains intact
- **One-time transients**: Action data is stored temporarily and deleted after use
- **Flexible configuration**: Admin can change pages at any time without breaking existing links
- **User-friendly**: Clear instructions in admin and on pages when accessed without parameters
